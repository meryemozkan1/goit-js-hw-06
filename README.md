# GoIT JavaScript Homework #6 (Module 6)

This project is the sixth JavaScript homework assignment within the GoIT Full Stack Developer program. It focuses on object context binding (`this`), object-oriented programming (OOP) principles, ES6 classes, and private class properties (`#`).

## 🚀 Live Demo
- [View Live Page](https://meryemozkan1.github.io/goit-js-hw-06/)

## 🛠️ Tasks Included
- **Task 1:** `customer` — Refactored object methods using the `this` keyword to manage user account balances, orders, and discounts.
- **Task 2:** `Storage` — A class managing product inventories with private fields (`#items`) and manipulation methods (`getItems`, `addItem`, `removeItem`).
- **Task 3:** `StringBuilder` — A class handling string accumulation and padding operations with private fields (`#value`) and methods (`getValue`, `padStart`, `padEnd`, `padBoth`).

## 🛠️ Technologies & Tools Used
- **JavaScript (ES6+):** OOP classes, private class fields, context binding (`this`).
- **Prettier:** Code formatting.
- **Git & GitHub:** Version control and GitHub Pages deployment.
